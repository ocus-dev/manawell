# R06 — Build a repeatable visual tuning scene

Depends on R05. Create an isolated developer preview using the same resolver, weapon/projectile and harvest logic, with an injected test account. Never grant mana or change the player's profile. Use a single target, spaced crowd and durable boss-sized target; provide fixed preset builds for standard, fan and Lance plus fast-cycle/large-cycle harvesting.

Show actual fired/hit projectiles, elapsed time, measured damage, DPS, harvest cycles and total mana beside expected formula values. Include comparable equal-spend presets from R01. Make it easy to see projectile-speed differences and pierce behavior at real game scale; pause/step/reset are useful if already supported, but do not build a second combat engine.

Produce a short repeatable check command and screenshots or clips demonstrating 1/3/5 shots. Use compact tracers/muzzle feedback so shots stay distinct without obscuring enemy telegraphs. Record performance at maximum ranks and live enemy cap; disclose machine and test duration. This scene informs R07 balance and does not replace campaign playtesting.

Acceptance: isolated profile, shared runtime logic, repeatable preset comparisons, visible multishot/speed/cadence evidence and honest measured results. Completion note: isolated Standard/Fan/Lance/harvest tuning scene and test implemented; tuning command passes.
