## Timeout correction

The reproducible 45-second timeout was an assertion-abort path, not a live gameplay loop. `encounter_test.gd` advanced a one-second harvest in fixed steps; the accumulated cycle progress could sit just below `1.0`, causing the first tank assertion to abort `_init` before `quit(0)`. After the cycle-boundary correction, the test reached the next assertion, which required smoothed harvest feedback to equal the extraction rate even though the controller reported a positive interpolated value (`3.966...` for a `2.0` rate). That harness assertion was narrowed to the behavior it needs to verify. `ld03_runtime_test.gd` did not reproduce the same failure in the final isolated run.

The repeated headless warning about loading `res://assets/world_map/master.png` as an image resource is unrelated to LD03.
