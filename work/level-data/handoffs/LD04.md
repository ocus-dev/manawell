## Decisions

- Existing migrated campaign JSON remains unchanged. No illustrative 24-kill quota was enabled in shipped levels.
- Objective state is per run and reset on retry; credited IDs are persisted only for an active suspended run.
- Objective credit is separate from loot identity/roll state. LD05 still owns reward entitlements and pending delivery.
- Ordinary early extraction remains an account banking path; campaign commissioning still requires the campaign terminal success path and a valid well seal/surge result. Failed seals cannot commit or commission.
- Completion does not launch a successor. Campaign state only makes prerequisites eligible after an explicit terminal commit.
- Boss objectives require the configured named boss spawn ID; ordinary kills cannot satisfy them.
- Objective state is carried inside the current campaign snapshot/config payload to preserve existing persistence boundaries. LD06 owns frozen definition redesign and compatibility migration.
