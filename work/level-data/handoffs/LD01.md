## Contract decisions

- Loader accepts only manifest-listed JSON files under the supplied data root; relative paths must remain inside that root.
- v1 bounds are 64 acts, 256 levels per act, 32 prerequisites, 128 waves, 64 wave entries/pool entries, 32 guarantees, and 100000 for authored counts.
- Shared catalog IDs are conservative LD01 adapters: `foundry`, `foundry_physical_v1`, `foundry_surges_v1`, the four current monster IDs, current production base IDs, and item levels 1-3.
- Resolved output omits authoring-only fields, fills normalized defaults, and includes `content_hash`; content hashes are stable across JSON key order and whitespace.
- LD01 validates the full typed union and graph/reference rules but does not route runtime gameplay. Kill-quota count eligibility and boss spawn identity are validated structurally here; runtime semantics remain downstream stories.
