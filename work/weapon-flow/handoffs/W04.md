## Publication contract

- W04 consumes a W03 draft and a W02 completed preparation directory identified by `draft.art.job_id`.
- The publisher copies `square-icon.png` and `world-sprite.png` into versioned `res://assets/weapons/<weapon_id>/<revision>/`, stores definition and recipe under `res://data/weapons/<weapon_id>/<revision>/`, and writes the runtime index last.
- `res://data/weapons/history/` retains prior index snapshots. Rollback changes only the index; old definition, recipe and asset files remain readable.
- Repeating an identical publication is a no-op. Same-revision content changes and attempts to publish an older revision are rejected.
- JSON and asset files are repository-local and included by the existing Godot project export defaults; resource existence is checked alongside file/hash validation. No `project.godot` change was required.
