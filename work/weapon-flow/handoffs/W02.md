## Protocol and interfaces

- Start: `weapon.ps1 start --source <png> --root <runs> [--cutout transparent|corrected --mask <png> --crop x,y,w,h --pivot x,y]`.
- Resume: `weapon.ps1 resume --job-id <id> --root <runs>`.
- Status: `weapon.ps1 status <id> --root <runs>` emits the complete JSON manifest.
- `manifest.json` is durable state; `progress.jsonl` contains machine-readable `stage_started`, `stage_complete`, `settings_changed`, `submission_reconciled`, `blocked`, `already_complete` and `job_complete` events.
- `gpu_work` is explicit and remains false for transparent/corrected inputs. Unknown Comfy submissions are represented as `needs_reconciliation`; reconciliation can only adopt a found token and never blindly resubmits.
- Settings hashes invalidate all derived outputs while retaining the source snapshot. Completed jobs verify output hashes and return without GPU work.
- `grip-calibration.json` records top-left pixel coordinates plus normalized coordinates relative to `cropped-source.png`; no combat stats, rarity, names or behavior are inferred.
